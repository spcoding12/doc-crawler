## 2024-08-28 - Optimizing detector sequence
**Learning:** Sequential detection logic (like framework identification in `detector.py`) often includes both early return checks and data extraction checks. Placing generic attribute/class checks first can unintentionally bypass specific data extractions (like reading a framework version from a `<meta>` tag). While combining checks can be faster, early returns must be careful not to skip version extraction.
**Action:** When optimizing detection logic, extract necessary data elements first before short-circuiting with class or script tag checks. This ensures version information is captured without traversing the DOM unnecessarily. Using `soup.find_all(class_=['class1', 'class2'])` combined with lambda functions is significantly faster than CSS selectors in BeautifulSoup.
