## 2024-05-14 - Optimize BeautifulSoup queries and serialization
**Learning:** The previous framework detection relied heavily on BeautifulSoup's CSS selectors (`.select`) and looping over candidates. Furthermore, serializing entire tags to string (`str(tag)`) was extremely slow compared to native `.text` extraction. Passing a list of classes to `.find(class_=[...])` allows traversing the DOM just once. Extracting version strings from metadata early rather than doing generic class fallbacks first prevents incorrect skipping.
**Action:** In `src/detector.py`, replace `.select()` calls with `.find()` and `.find_all()`. Use lists of classes for `class_` arguments. Avoid `str(tag)` serialization entirely, relying on `.text` and attribute extraction. Order logic appropriately (extract data before early returns).
