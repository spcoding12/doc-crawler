## $(date +%Y-%m-%d) - BeautifulSoup Parsing and Selector Overhead
**Learning:** Using `soup.select()` with CSS selectors is significantly slower than direct `.find()` or `.find_all()` with attributes, especially inside iterative framework detection loops. Also, checking for text inside tags using `str(tag)` serializes the entire tag, imposing a massive performance penalty compared to accessing `.text` or `.get('src', '')`. Furthermore, when evaluating framework characteristics, generic class existence early returns can mistakenly skip more specific data extraction (like reading versions from `<meta>` tags) if not evaluated in the correct sequence.
**Action:** Replace `.select()` with `.find()` or `.find_all()` passing `class_=[list_of_classes]` for consolidated DOM traversal. Always evaluate specific tag lookups (like versions in `<meta>`) before generic class fallback checks. Never use `str(tag)` for string matching within a tag; use `.text` or explicit attribute checks.
