## 2024-05-24 - Pass framework down to extractor to prevent redundant DOM tree parsing
**Learning:** In a multi-page crawler architecture like this codebase, `detect_framework` is called globally once (in `main.py`). However, during the per-page extraction loop, `extract_content` is called without the `framework` argument. This forces `extract_content` to call `detect_framework` again for every single page, which internally parses the entire HTML string into a BeautifulSoup object (`BeautifulSoup(html, 'lxml')`). This redundant parsing causes significant performance overhead when processing hundreds of pages.
**Action:** Pass the globally detected `framework.name` down to the `extract_content` function call in the multi-page loop in `src/main.py`. This leverages the existing `framework: Optional[str] = None` argument in `extract_content` and bypasses the redundant `detect_framework` call and DOM tree construction per page.
