## 2024-04-08 - [BeautifulSoup Performance: `find()` vs `.select()`]
**Learning:** In BeautifulSoup, using `soup.select()` with CSS selectors is significantly slower (up to ~8x slower based on benchmarks) than using direct lookups with `soup.find()` or `soup.find_all()` paired with attribute or class list matching. `select` parses the CSS selector and repeatedly traverses the DOM for matches, whereas `find` short-circuits traversing down the DOM. Passing a list of classes to the `class_` argument of `find` acts as an optimized single-pass OR condition.
**Action:** Always prefer `soup.find()` and `soup.find_all()` over `soup.select()` when querying flat, identifiable properties like specific `class` arrays or `name` attributes, particularly when executing framework detection or iterating over large HTML bodies repeatedly.
