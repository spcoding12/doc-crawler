## 2024-05-24 - Optimizing HTML Parsing with BeautifulSoup in framework detector
**Learning:** `soup.select()` with CSS selectors is significantly slower than `soup.find()` or `soup.find_all()` with direct attribute/class lookups in `BeautifulSoup`. Passing a list of classes to `class_` parameter in `soup.find()` acts as an optimized single-pass OR check that heavily reduces DOM traversal overhead, showing a ~7x speedup in framework detection loops compared to sequential `.select()` checks. `str(tag)` incurs a large serialization penalty.
**Action:** Replace `soup.select()` with `soup.find()` or `soup.find_all()` where possible. Combine multiple independent class existence checks into a single `soup.find(class_=['class1', 'class2'])`. Use `.text` or `.string` or explicit attribute checks (like `get('id')`) instead of `str(tag)`.
