## 2024-08-20 - Optimize BeautifulSoup Framework Detection
**Learning:** `soup.select()` and stringifying whole tags (`str(tag)`) are significantly slower in BeautifulSoup compared to direct attribute checks or using `soup.find()`. For framework detection where we only need to check if an element exists, using `.find()` instead of `.select()` and checking `.get('src')` and `.text` instead of `str(tag)` yields a ~20x to ~100x speedup. The previous code was iterating over all matches from `.select()` but returning on the first match anyway, which is exactly what `.find()` does naturally. Also, placing early exits (like checking for classes) before metadata checks prevents redundant parsing.
**Action:** Replace `soup.select()` with `soup.find()` for existence checks. Replace `str(tag)` with `.text` and `.get('src')` for checking content within scripts or tags.
