## 2024-04-11 - Optimize BeautifulSoup performance by replacing repeated .select_one() with .find(class_=list)
**Learning:** Checking multiple CSS selectors sequentially via `.select_one()` or `.select()` in BeautifulSoup is extremely slow (e.g., 37 seconds for 1000 iterations over small DOMs). When checking for the existence of multiple possible classes to detect frameworks, calling `soup.find(class_=['class1', 'class2', ...])` traverses the DOM tree exactly once and is ~4.5x faster.
**Action:** Consolidate multiple independent class checks into a single-pass operation using `soup.find(class_=[...])` instead of iterating over a list of selectors calling `soup.select_one()` on each. Use targeted `attrs` lookups like `soup.find('meta', attrs={'name': 'generator'})` for attributes.
