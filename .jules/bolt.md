## 2024-09-24 - Avoid `str(tag)` in BeautifulSoup loops
**Learning:** In `src/detector.py`, checking if a string is present in a script tag by converting the entire tag to a string using `str(tag)` is very slow. It serializes the entire tag (which could be large). Using `tag.text` or `tag.string` is much faster, but `.string` can be None if the tag has multiple children, and `.text` doesn't include attributes. A faster and safer way to check for framework signatures in `<script>` tags is to check the `src` attribute (via `tag.get('src', '')`) and the inner text (via `tag.text` or checking it explicitly). Also, passing `('script', ...)` to `soup.select` inside the indicators loop forces a CSS selector parse and searches all script tags. It's faster to do a dedicated `soup.find_all('script')` loop for this specific check.
**Action:** Replace `('script', lambda tag: 'docusaurus' in str(tag))` in `detect_docusaurus` with a dedicated loop over `soup.find_all('script')`, checking `tag.get('src', '')` and `tag.text` instead of `str(tag)`. Apply similar fixes to other detectors using `.string` (like `detect_vuepress` and `detect_docsify`) which should fall back to `.text` to avoid missing nested contents and avoid `str()`.
