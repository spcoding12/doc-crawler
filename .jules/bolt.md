## 2024-03-24 - Optimize BeautifulSoup CSS Selection in Detector
**Learning:** Using `soup.select()` within loops in `src/detector.py` incurs significant parsing overhead due to the repeated execution of CSS selectors. Moreover, checking specific selectors one by one and then attempting to extract data if a generic match occurs causes redundant work and can even lead to incorrectly skipping specific attribute evaluation. Benchmarking shows that direct attribute lookups (e.g., `soup.find_all(class_=[...])`) and using `lambda` on `attrs` is about 3x faster and more reliable for extracting metadata and finding specific markers compared to looping over `soup.select()`. Also, using `.text` instead of `str(tag)` on elements like `<script>` avoids the expensive tag serialization.
**Action:** Replace `soup.select()` loops with `soup.find()` / `soup.find_all()` using direct attribute/class matching. Consolidate class checks into a single list passed to `class_`. Use `.text` safely instead of `str()` for parsing tag contents.
