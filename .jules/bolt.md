## 2024-05-16 - Prevent Redundant BeautifulSoup Parsing in extract_content\n**Learning:** In a multi-page crawler architecture, calling `extract_content` without passing the known framework string forces `detect_framework` to be called repeatedly on every single page. This redundant `detect_framework` call rebuilds the expensive `BeautifulSoup` object from scratch. By extracting the framework logic globally, you prevent redundant and expensive DOM tree parsing on every page.\n**Action:** Pass the `framework` string argument to `extract_content` inside the loop to avoid recreating BeautifulSoup trees and calling detection repeatedly.
