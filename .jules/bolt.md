## 2024-07-01 - Optimizing BeautifulSoup DOM Traversal
**Learning:** In BeautifulSoup, using `soup.select()` with CSS selectors is significantly slower than using `soup.find_all(class_='...')`. Combining multiple class checks into a single `soup.find(class_=['class1', 'class2'])` acts as an optimized OR check and traverses the DOM tree only once, providing massive performance gains compared to sequential `.select()` or even sequential `.find_all()` calls. Furthermore, serializing tags to strings (`str(tag)`) for string matching (like checking script tags for framework keywords) incurs a severe serialization penalty compared to checking `tag.get('src', '').lower()` and `tag.text.lower()`.
**Action:** When extracting data or identifying frameworks from HTML documents, replace multiple sequential `.select()` or `.find_all()` calls with a single `soup.find_all(class_=[...])` or `soup.find(class_=[...])`. Replace `str(tag)` matching with explicit property checks like `.get('attr')` and `.text`.
