## 2025-02-23 - BeautifulSoup Performance Bottleneck in detector.py
**Learning:** Using `soup.select()` with CSS selectors, and specifically calling `str(tag)` on BeautifulSoup tags to perform string matching (e.g., `lambda tag: 'docusaurus' in str(tag)`), is a massive performance bottleneck. `str(tag)` forces a full re-serialization of the tag and all its children into an HTML string, completely defeating the purpose of parsing it in the first place. This takes up to 300-400ms per iteration on a modest page.
**Action:** Replace `str(tag)` checks with direct attribute lookups (`tag.get('src', '')`) or text content access (`tag.text` or `tag.string`). For element searches, use `.find()` and `.find_all()` instead of `.select()` where possible, and restructure sequential lookups so that `.find()` can short-circuit early (using variable assignment) to avoid repeatedly traversing the tree for elements that can be found in a single pass.
