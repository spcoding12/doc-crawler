## 2024-05-30 - DOM Traversal and Serialization Bottlenecks
**Learning:** `soup.select()` with CSS selectors and serializing tags with `str(tag)` (like `<script>`) incurs severe performance penalties in `bs4`. Using `str(tag)` on large inline scripts is extremely slow. `soup.find_all('script')` and checking `.text` is much faster. Also, checking for specific attributes like version strings in meta tags *before* early returns from class checks prevents skipping detailed extractions. Finally, combining multiple class checks into a single `soup.find(class_=['class1', 'class2'])` acts as a fast, single-pass OR operation, drastically outperforming iterative list lookups.
**Action:** Replace all `.select()` calls with `soup.find()` / `soup.find_all()` using direct attribute/class lookups. Combine multiple class-based indicators into single-pass list lookups. Use `.text` over `str()` for tag serialization, while carefully checking relevant attributes like `id` and `src` to avoid regressions.
