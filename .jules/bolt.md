## 2025-05-24 - Optimize BeautifulSoup CSS selectors and str(tag)
**Learning:** In a large HTML document, using BeautifulSoup's `.select()` is significantly slower than `.find()` or `.find_all()` because it incurs CSS selector parsing overhead. Furthermore, executing `str(tag)` to serialize an entire element tree just to search for a string is up to 100x slower than checking `tag.text` and specific attributes. Grouping multiple independent class existence checks using a list in `.find(class_=[...])` provides a substantial performance boost by combining them into a single-pass traversal.
**Action:** Replace `.select()` with `.find()` / `.find_all()`. Avoid `str(tag)` on large nodes in favor of `.text` + explicit attribute checks. Consolidate multiple independent existence checks into a single `.find(class_=[...])` call whenever evaluating multiple candidate tags for presence.
