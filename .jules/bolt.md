## 2024-09-06 - BeautifulSoup DOM Traversal Optimization
**Learning:** Checking for multiple classes using `.find(class_=['class1', 'class2'])` is significantly faster than using `.select()` with CSS selectors inside a loop. Furthermore, checking script content using `.text` and attribute extraction `.get('src')` is orders of magnitude faster than serializing the entire tag via `str(tag)`. Finally, specific data extraction (e.g., getting a version from a `<meta>` tag) must be performed *before* checking early-return existence checks to prevent missed extractions.
**Action:** When inspecting DOM structures across multiple framework detectors, replace `indicators` array mapping with direct, consolidated `.find()` calls, and always prefer `.text` over `str()` to avoid serialization overhead.
