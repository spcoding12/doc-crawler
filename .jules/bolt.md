## 2024-06-21 - [BeautifulSoup Performance]
**Learning:** Checking elements via `soup.select('.class-name')` vs `soup.find(class_='class-name')` vs `soup.find(class_=['class1', 'class2', 'class3'])`. `find(class_=[...])` is significantly faster than querying multiple individual selectors or using CSS selectors. However, for string/src tag checking, iterating `soup.find_all('script')` and checking `tag.text` and `tag.get('src', '')` is much faster than `tag in str(soup)` because the latter stringifies the whole object which incurs massive serialization overhead.
**Action:** Replace `soup.select(selector)` and `soup.find(class_=...)` calls in `detector.py` with multi-class checks via list. Avoid checking if a substring is in `str(tag)`. Replace with `substring in tag.text` or check attributes natively.
