## 2024-05-23 - BeautifulSoup Performance Optimization in detector.py
**Learning:** Using `soup.select()` repeatedly with CSS selectors and stringifying full tags (`str(tag)`) for string checking is significantly slower than using `soup.find_all(class_=[...])` and checking `.text` or `.get('src', '')`. The former involves repeatedly building intermediate lists and parsing CSS, while `find_all` with a list of classes is heavily optimized in BeautifulSoup. Additionally, `str(tag)` serializes the entire tag which is incredibly expensive compared to just accessing the `.text` property.
**Action:** Replace `soup.select()` within loops with unified `soup.find()` or `soup.find_all(class_=[...])` checks where applicable, and use `.text` instead of `.string` or `str(tag)` when checking content in script tags.
