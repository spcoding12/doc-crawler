## 2024-05-24 - Optimize BeautifulSoup Selectors
**Learning:** In BeautifulSoup, using `.select()` with CSS selectors is significantly slower than using `.find()` or `.find_all()` with direct attribute lookups, especially when checking for the existence of elements multiple times. The original codebase frequently used `soup.select(selector)` combined with a lambda to filter elements for framework detection (like in `detect_docusaurus`, `detect_vuepress`, `detect_mkdocs`, `detect_gitbook`).
**Action:** Replace `soup.select()` loops with direct `.find()` or `.find_all()` calls where possible (e.g. checking `class_`, `id`, `name`). Consolidate class checks into single lists (`class_=['class1', 'class2']`). Check for specific elements like `<meta name="generator">` directly first, as they provide high confidence quickly.
