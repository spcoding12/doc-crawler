## 2024-05-18 - Extract Content Framework Bypass Optimization
**Learning:** In `src/main.py`, the `extract_content` function is called for every page in a loop to extract content. By default, `extract_content` calls `detect_framework(html)` (which uses BeautifulSoup to parse and check indicators) to detect the framework on every single page. However, we already know the `framework` string from the initial page scan (e.g., via `framework = detect_framework(result.html)`). Passing the `framework` string as an argument directly into `extract_content` bypasses the redundant and expensive `detect_framework` DOM parsing operation on every page.
**Action:** When extracting content across multiple pages where the framework is already known globally, explicitly pass the `framework` parameter to `extract_content` to skip redundant detection overhead.
