## 2024-05-18 - BeautifulSoup Select vs Find Optimization
**Learning:** Sequential `.select()` lookups with CSS selectors (especially when evaluating multiple candidate classes on a large DOM tree) scale terribly. A massive performance bottleneck in HTML detection logic happens when checking for multiple element states using looped `soup.select()`. Additionally, executing `str(tag)` on a BeautifulSoup node (like a large JavaScript snippet in a `<script>` tag) incurs a devastating serialization performance hit.
**Action:** Replace looped `soup.select(selector)` calls with a single-pass array lookup using `soup.find(class_=['a', 'b', ...])`. This performs a single DOM traversal and checks for any matching condition. To inspect text within large tags (like script elements), always use `tag.text` instead of `str(tag)` or `tag.string`, but remember to explicitly check attributes like `tag.get('src')` which are lost when bypassing stringification.
