## 2024-05-18 - BeautifulSoup DOM Traversal Optimization
**Learning:** Using `soup.select()` to query elements by class or tag in BeautifulSoup introduces significant overhead because it relies on the `soupsieve` external CSS parser, which builds and traverses the entire DOM tree to match CSS selectors. Benchmarks showed `select` taking ~2.9s versus `find` taking ~0.02s for identical tasks. Additionally, passing a list of classes to the `class_` argument in `soup.find()` (e.g., `soup.find(class_=['class1', 'class2'])`) acts as an extremely efficient OR condition that completes in a single pass, significantly outperforming multiple independent `select` or `find` queries.
**Action:** Always prefer native `soup.find()` and `soup.find_all()` with direct attribute lookups (e.g., `attrs={'name': 'generator'}`) over `.select()` when possible. When checking for the presence of ANY of multiple classes, use `class_=['a', 'b']` to collapse multiple O(N) traversals into a single early-exit O(N) traversal.
