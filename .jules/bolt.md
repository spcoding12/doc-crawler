## 2025-05-20 - [BeautifulSoup Optimization Pattern]
**Learning:** In a multi-page crawler architecture, optimizing framework detection by replacing repetitive `cssselect` calls with single-pass `soup.find(class_=[...])` and early-return `<meta>` tag lookups yields a ~3.8x speedup. Also, `str(tag)` causes severe serialization penalties; using `.text` or `str(tag)` sparingly and attribute extraction (`.get('src')`) is much faster. Note: `detect_docusaurus` uses `str(tag)` over `.text` purposefully as `script.text` misses code embedded differently or src strings, but applying this pattern broadly avoids regressions.
**Action:** Always prefer native `.find` with lists over `.select()` when checking for generic UI frameworks, and evaluate specific data extraction logic before fallback existence checks.
