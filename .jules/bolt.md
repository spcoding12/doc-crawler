## 2024-06-20 - [Optimize Framework Detection using BeautifulSoup Native Methods]
**Learning:** `soup.select()` and stringifying BeautifulSoup tags (`str(tag)`) are significantly slower than using native `.find()` / `.find_all()` with direct attribute lookups and checking `.text`. In the `src/detector.py`, `detect_docusaurus` uses `str(tag)` on script tags, which is extremely slow. Also, CSS selectors via `select` can be replaced with targeted `find` operations to speed up detection substantially.
**Action:** Replace `soup.select()` with `.find()` or `.find_all()` using direct attribute checks or class lists. Replace `str(tag)` with `tag.text` for text matching in tags. Ensure specific extraction (like version from meta tags) is done directly using `find` without evaluating a full selector list repeatedly.
