## 2025-02-28 - BeautifulSoup Framework Detection Optimization
**Learning:** In BeautifulSoup, using `.select()` to traverse DOM elements with CSS selectors incurs high parsing overhead. In `src/detector.py`, checking multiple `.select()` calls sequentially per framework type was extremely slow (~7.7s for 50 passes on a large document). Consolidating independent class checks into a single-pass `soup.find(class_=[...])` list operation, and using `attrs={...}` directly acts as an optimized OR check and traverses the DOM tree exactly once.
**Action:** Use `.find()` or `.find_all()` with direct attribute lookups instead of `.select()` with CSS selectors to avoid parsing overhead. For multiple class selections, pass a list to the `class_` parameter (e.g. `soup.find(class_=['class1', 'class2'])`). Assign the result of `.find()` to avoid redundant DOM traversal.
