## 2024-05-24 - Pre-compiling individual regexes vs Single large regex
**Learning:** In Python, when running many regex substitutions over large Markdown documents (which happens frequently in `clean_markdown` for every extracted page), pre-compiling multiple individual regular expressions using `re.compile()` at the module level is significantly faster than compiling them inline. Surprisingly, benchmarking results for this project also indicated that pre-compiling multiple individual regexes and iterating over them is slightly more performant than joining multiple patterns into a single large regex using the `|` (OR) operator for these specific patterns and large text blobs. Furthermore, pre-compiling `.match()` calls inside tight loops (like checking lines of a markdown file) yields measurable speedups.
**Action:** When performing regex substitutions or matches in frequently called functions or loops in Python, always pre-compile the patterns at the module level using `re.compile()`. Avoid dynamically compiling regexes, and verify if joining them with `|` is actually faster via benchmarking before committing to a single massive regex.
