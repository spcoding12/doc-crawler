## 2024-03-01 - Optimizing BeautifulSoup DOM Traversal in Framework Detection
**Learning:** Using `soup.select()` with CSS selectors is significantly slower than using native BeautifulSoup methods like `soup.find()` and `soup.find_all()`. Furthermore, when testing multiple class names or attributes, passing a list to `class_` (e.g., `soup.find(class_=['class1', 'class2'])`) is an optimized OR check that prevents multiple sequential traverses of the entire DOM tree. Checking `<meta>` tag generators first before scanning the DOM tree for class names is also much faster as an early exit.
**Action:** When evaluating presence of elements across an entire document in performance-critical paths like detectors, replace lists of `.select()` calls with optimized `.find()` calls using list attributes, and order checks from most specific/easiest to find (like `<meta>` generator tags) to least specific (like class structures).
