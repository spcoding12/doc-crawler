## 2024-05-24 - Avoid `str(tag)` in BeautifulSoup loops
**Learning:** Calling `str(tag)` on BeautifulSoup objects to perform string matching inside a loop is extremely inefficient because it forces the serialization of the entire HTML tag. Using `.text` combined with explicit attribute checks (like `tag.get('src')`) is roughly 10x faster and maintains exact matching behavior. Furthermore, replacing `script.string` with `script.text` is actually a robustness improvement (it handles multiple children properly) rather than a direct performance optimization, as `.string` is technically a fast property access but brittle, while `.text` traverses the tree.
**Action:** Always favor specific attribute extraction and `.text` over full stringification when checking for signatures inside heavy loop iterations with BeautifulSoup.
