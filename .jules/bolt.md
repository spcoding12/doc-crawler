## 2024-05-24 - Framework Detection Optimization
**Learning:** Re-evaluating large DOM trees using `BeautifulSoup.select()` causes significant performance overhead due to CSS selector parsing, and `.string`/`str()` fails or causes serialization slow-downs on tags with complex children. Additionally, using a loop with indicator tuples forces multiple separate tree traversals, slowing down generic fallbacks unnecessarilly.
**Action:** Consolidate class checks into single-pass `.find(class_=[...])` lookups and use direct attribute lookups like `attrs={'name': 'generator'}`. Avoid `.select()`. Prioritize version data extraction checks before broader generic class checks to preserve version identification. Substitute `str(tag)`/`.string` with `.text` for fast and safe tag text extraction.
