## 2024-05-17 - BeautifulSoup Performance Pattern
**Learning:** Consolidating multiple independent class checks into a single-pass operation by passing a list to the class parameter (e.g., `soup.find(class_=['class1', 'class2', ...])`) acts as an optimized OR check that traverses the DOM tree exactly once, further reducing overhead compared to checking selectors one by one using `.select()` or individual `.find()` calls. Avoiding `.select()` in favor of `.find()` with attributes is also a major performance win as it avoids parsing CSS selectors.
**Action:** When evaluating multiple candidate tags based on class or other attributes, use `.find()` or `.find_all()` with a list of values instead of iterating over multiple selectors. Assign the result to a variable if both checking for existence and extracting data to avoid redundant DOM traversal.
